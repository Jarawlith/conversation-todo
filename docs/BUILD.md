# Build / 构建

All project-specific application, packaging, and documentation work was generated by AI. Third-party dependencies retain their own authorship and licenses.

## Windows x64

Requirements: Windows 10 / 11, Windows PowerShell 5.1, .NET Framework C# compiler, Node.js **24.19.0** Windows x64 executable, and official Inno Setup **6.7.3**.

Use official downloads: [Node.js](https://nodejs.org/dist/v24.19.0/) and [Inno Setup](https://jrsoftware.org/isdl.php). Review vendor licenses for your distribution. Do not commit downloaded toolchains, credentials, or runtime data.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -NodeExe C:\Tools\node.exe -ISCC "C:\Tools\Inno Setup 6\ISCC.exe"
```

Result: `dist/ConversationTodo-Mainland-Setup-0.7.exe`. The build compiles the launcher and Native Messaging host, bundles Node.js and its license, and builds only the mainland installer. Installation generates absolute machine-local paths; those files are never checked into Git.

构建脚本将运行环境放在应用目录，不修改系统 Node.js。不要把 `service.json`、客户令牌、自己的密钥或运行数据打进公开安装包。公共内置服务尚未开放。

## Checks / 验证

With Node.js on PATH:

```powershell
npm test
New-Item -ItemType Directory .build -Force
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File tests/test-settings-v3.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File tests/test-model-settings.ps1
```

`npm test` uses fake requests to check incremental analysis, edited messages, checkpoints, request formatting, exact mainland model enforcement, authentication, and per-account limits. It does not charge a model. The model-settings UI test refreshes the public OpenRouter directory but does not perform inference. UI tests encrypt dummy credentials in temporary test directories and render synthetic settings previews.

The release installer was tested with Chinese and spaced paths, bundled Node.js, the Native Messaging host, and uninstall data preservation. Installer integration tests excluded registration and shortcuts to avoid replacing an existing development installation. This is not a clean virtual-machine or broad device compatibility certification. No CI workflow or automatic public service deployment is configured.
